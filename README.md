# SerIQ — AI-помощник для домашней реабилитации

Проект команды на **AI-Sana Shakarim Solveathon: AI & Medicine-2026**, кейс SerIQ (трек колледжей и университетов).

## Задача

По видео с камеры или загруженной записи оценить цикл упражнения на разгибание локтя (**E02**) и показать пользователю нейтральный результат: «Выполнено» или «Проверьте инструкцию».

Требования ТЗ:

1. Сценарий тренировки: видеоинструкция и захват движения (камера или загрузка видео).
2. Ключевые точки руки через pose-estimation, отслеживание цикла разгибания локтя.
3. Собственная модель на последовательностях координат или углов: классификация цикла `complete` / `incomplete` с оценкой уверенности и сравнением с базовым классификатором. При низкой уверенности приложение предлагает пересмотреть инструкцию, без медицинских указаний. Разбиение train/validation/test строго по ID добровольца; метрики: balanced accuracy, F1, матрица ошибок.
4. Локальная сводка занятия: число распознанных циклов, их классы, наглядное отображение.
